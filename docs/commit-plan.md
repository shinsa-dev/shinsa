# Commit plan

How to split the uncommitted tree into conventional commits, in order. Each commit message is the subject line
alone, with no body. Only the final tree was verified (every gate passed three times in a row); a commit in the
middle of the sequence is not guaranteed to build on its own, since core, the server and the web change together,
so land the sequence as a whole.

**Before the first commit**, unstage everything: an earlier `git add` left about 490 paths in the index, and
`git commit` takes the whole index. Run `git restore --staged .`, then the commands below in order. Each `git add -A`
takes additions, changes, deletions and both sides of a rename under its paths; a later commit that names a parent
folder (`apps/server/src`, `apps/web`) takes only what the earlier commits left there, so keep the order.
`git status --short` is empty after the last one.
